# Nithishkumar K — Premium Portfolio

Next.js 14 + TypeScript portfolio with a premium dark UI, responsive layout, animated hover states, featured projects, experience, skills and a live GitHub repository browser.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
- Profile image is included at `public/profile.jpg`.
- GitHub repositories are loaded from the public GitHub API at runtime, so the Projects section can showcase the full repository collection without manually maintaining 40 cards.
- Update `data/portfolio.ts` for profile details, featured projects, skills, experience and education.
- Add your final resume as `public/resume.pdf` to activate the Resume button.
- Replace the placeholder LinkedIn URL with the real profile URL.
